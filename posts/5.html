Windows 11 终端美化指南：从默认黑框到高颜值命令行

技术 2026-11-11
Windows终端美化Windows TerminalOh My Posh

Windows 11 自带的 Windows Terminal 远比老式 cmd 黑框强大：多标签页、GPU 加速渲染、亚克力透明背景，还能自由更换字体与配色。本文带你一步步把默认终端美化成一个赏心悦目的工作台。

1. 为什么要从 cmd 换到 Windows Terminal

旧版命令提示符（cmd）只能单窗口、字体丑、不可定制。Windows Terminal 是微软官方开源的现代终端，支持：

  • 多标签 / 多窗格：一个窗口里同时跑 PowerShell、WSL、cmd。
  • 等宽 Nerd 字体：正确显示各种图标与连字。
  • 亚克力与透明度：让终端融入桌面壁纸。
  • 完整配色方案：一键切换 Catppuccin、Tokyo Night 等主题。

2. 第一步：安装并设为默认

Windows 11 已自带 Windows Terminal；若没有，用 winget 安装：

winget install --id Microsoft.WindowsTerminal -e

安装后在「设置 → 系统 → 面向开发人员」中，把终端的默认改为 Windows Terminal。

3. 第二步：换上等宽 Nerd 字体

很多图标（如 git 分支符号）需要 Nerd Font 才能显示，普通 Consolas 会变成豆腐块。推荐：

  • Cascadia Code NF（微软官方，连字优雅）
  • Fira Code NF（程序员最爱，连字丰富）

从 Nerd Fonts 官网 下载安装后，打开终端设置（Ctrl + ,）→ 外观 → 字体，选择 CascadiaCode NF。

4. 第三步：配色方案与主题

Windows Terminal 内置几十种配色，也可导入社区主题。打开设置 → 配色方案，挑一款喜欢的，例如 Catppuccin Mocha 或 Tokyo Night。想全局统一，可在 settings.json 的 profiles.defaults 里指定：

{
  "profiles": {
    "defaults": {
      "font": { "face": "CascadiaCode NF", "size": 11 },
      "colorScheme": "Catppuccin Mocha"
    }
  }
}

5. 第四步：亚克力背景与透明度

让终端半透明、透出桌面，是最容易出效果的一步：

{
  "profiles": {
    "defaults": {
      "useAcrylic": true,
      "acrylicOpacity": 0.85,
      "background": "#1e1e2e"
    }
  }
}

acrylicOpacity 越接近 1 越不透明；调到 0.7 左右能隐约看到壁纸，质感最佳。

6. 第五步：用 Oh My Posh 美化提示符

Oh My Posh 能把 PowerShell / bash / zsh 的提示符变成带 Git 状态、路径、耗时等信息的炫酷状态栏。

6.1 安装

winget install JanDeDobbeleer.OhMyPosh -e
oh-my-posh font install

6.2 应用主题

在 PowerShell 中执行（主题路径可在 $env:POSH_THEMES_PATH 查看）：

oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\catppuccin.omp.json" | Invoke-Expression

6.3 写入 $PROFILE 持久化

让每次启动自动加载：

notepad $PROFILE

在打开的文件里加入上面那条 oh-my-posh init ... 命令并保存即可。

7. 一份可直接用的 settings.json

把下面内容合并进 Windows Terminal 的 settings.json（设置 → 打开 JSON 文件），即可同时拥有字体、配色、透明背景：

{
  "profiles": {
    "defaults": {
      "font": { "face": "CascadiaCode NF", "size": 11 },
      "colorScheme": "Catppuccin Mocha",
      "useAcrylic": true,
      "acrylicOpacity": 0.82,
      "background": "#1e1e2e",
      "cursorShape": "filledBox"
    }
  },
  "schemes": [
    {
      "name": "Catppuccin Mocha",
      "background": "#1e1e2e",
      "foreground": "#cdd6f4",
      "cursorColor": "#f5e0dc",
      "black": "#45475a",
      "red": "#f38ba8",
      "green": "#a6e3a1",
      "yellow": "#f9e2af",
      "blue": "#89b4fa",
      "purple": "#cba6f7",
      "white": "#bac2de"
    }
  ]
}

结语

到这里，你的 Windows 11 终端已经拥有了 Nerd 字体、协调配色、亚克力背景和精致的 Oh My Posh 提示符。一个好看的终端不仅能提升心情，也能让日常的命令行工作更顺手。继续探索主题与配置，把它调成属于你自己的样子吧。
