DLL 入门：如何编写并在 C/C++、C#、Python 中调用动态链接库

技术 2026-11-11
DLLWindowsC/C++Python动态链接库

在 Windows 上，你几乎每天都在和 DLL（Dynamic Link Library，动态链接库）打交道——系统里成千上万的 .dll 文件就是各种功能的共享模块。学会自己编写并使用 DLL，不仅能复用代码，还能给已有程序做插件化扩展。本文从「是什么」讲到「怎么用」，覆盖 C/C++、C# 与 Python 三种调用方式。

1. 什么是 DLL

DLL 是一段可被多个程序在运行时共享加载的二进制代码。和静态库（.lib 把代码直接编进 exe）不同，DLL 在运行时才被链接，多个进程可以共用同一份内存中的代码。

2. 为什么用 DLL

  • 代码复用：一套算法，C++、C#、Python 都能调用。
  • 节省内存：同一 DLL 在物理内存中只存一份，被多个进程共享。
  • 热更新 / 插件化：换掉 DLL 就能更新功能，不用重编主程序。
  • 职责分离：把不稳定或需授权的模块隔离在 DLL 里。

3. 用 C/C++ 编写并导出 DLL

关键是显式导出符号，并尽量用 extern "C" 避免 C++ 的名称修饰（name mangling）：

// mathlib.h
#ifdef MATHLIB_EXPORTS
#define API __declspec(dllexport)
#else
#define API __declspec(dllimport)
#endif

extern "C" API int add(int a, int b);
// mathlib.cpp
#include "mathlib.h"

extern "C" API int add(int a, int b) {
    return a + b;
}

编译后会得到 mathlib.dll（以及导入库 mathlib.lib）。

4. 在 C/C++ 中调用 DLL

有两种链接方式：

  • 隐式链接：编译时链接 .lib，运行时系统自动加载 DLL。
  • 显式链接：用 LoadLibrary + GetProcAddress 在代码里动态加载，更灵活。
// 显式链接示例
#include <windows.h>
typedef int (*AddFunc)(int, int);

HMODULE h = LoadLibraryA("mathlib.dll");
AddFunc add = (AddFunc)GetProcAddress(h, "add");
int r = add(2, 3);
FreeLibrary(h);

5. 在 C# 中通过 P/Invoke 调用

C# 用 DllImport 一行声明就能调用，注意调用约定要一致：

using System;
using System.Runtime.InteropServices;

class Program {
    [DllImport("mathlib.dll", CallingConvention = CallingConvention.Cdecl)]
    static extern int add(int a, int b);

    static void Main() {
        Console.WriteLine(add(2, 3));
    }
}

6. 在 Python 中通过 ctypes 调用

Python 标准库 ctypes 无需额外安装即可加载 DLL：

from ctypes import cdll, c_int

lib = cdll.LoadLibrary("mathlib.dll")
lib.add.argtypes = [c_int, c_int]
lib.add.restype = c_int
print(lib.add(2, 3))

7. 常见坑

  • 调用约定不匹配：__cdecl 与 __stdcall 必须和调用方一致，否则栈会错乱崩溃。
  • 位数不匹配：64 位程序不能加载 32 位 DLL，反之亦然，务必对齐 x86 / x64。
  • 依赖缺失：DLL 自身还可能依赖别的 DLL 或 VC++ 运行库，缺失会报「找不到模块」，可用 dumpbin /dependents 排查。
  • 名称修饰：C++ 导出函数名会被改写，记得用 extern "C" 或 .def 文件固定导出名。
  • 路径问题：运行时 DLL 要在 exe 同目录或系统 PATH 中，否则加载失败。

结语

DLL 把「共享、复用、可插拔」变成了 Windows 平台的底层能力。掌握它的编写与跨语言调用（C/C++ 的 LoadLibrary、C# 的 P/Invoke、Python 的 ctypes），你就能把核心逻辑用一种语言写好，再在各个语言里复用。动手写一个最小的 mathlib.dll，然后用三种语言各调一次，是理解它最快的方式。
