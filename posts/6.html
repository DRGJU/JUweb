从零到通关：我做的 Python 游戏化学习平台

技术 2026-11-11
Python游戏化学习项目前端

除了这个博客，我最近还做了一个小项目：一个浏览器里的 Python 游戏化学习平台。打开网页就能玩，把 Python 语法拆成 30 个关卡，边写边闯关，不用装环境、不用登录。

它是什么

一个纯前端的 Python 学习站点：首页选关，点进去看讲解、示例和挑战，写完代码立刻知道对不对，过关自动解锁下一关，进度存在本地浏览器里。

游戏化为什么有效

  • 即时反馈：写错马上知道，不用攒到月底。
  • 小步通关：每关只学一个知识点，成就感推着你继续。
  • 即开即玩：零启动成本，没有配环境的劝退感。

核心特性

  • 30 关 / 6 阶段：从变量循环到函数、文件、综合项目，难度递进，后续阶段自动锁定。
  • 5 种答题模式：代码编写、拖放编程、选择题、填空、分步引导，适配不同知识点。
  • 进度本地保存：基于 localStorage，关掉网页再打开进度还在。

技术实现

整个项目零后端：关卡数据集中在 data/levels.json 异步加载，主页与关卡逻辑分别在 js/game.js 与 js/level.js（ES6 类设计），进度用 localStorage 持久化，渲染时对输入做 HTML 转义防 XSS。视觉走简洁清爽路线，蓝紫渐变 + 卡片式布局，并做了响应式适配。

结语

这是我把「让编程更好玩」落地的一次尝试，和这个博客一样追求打开即用、轻量纯粹。欢迎去我的 GitHub（DRGJU）交流，后续我计划补全早期关卡并加入成就系统。
